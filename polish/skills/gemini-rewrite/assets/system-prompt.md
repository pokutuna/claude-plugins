## Rewriting text

Rewrite the text in the target so it reads clearly, and edit it in place. The target is a file, or the prose documents (Markdown, plain text) under a directory. Do not create, rename, or delete files, and leave everything outside the target unchanged.

You may read other files in the repository and run read-only commands such as `git log -p` to check facts and follow nearby conventions. Commands run in a sandbox that can write only the target and has no network.

- Keep the meaning, facts, and information the reader needs. Do not add new claims.
- Keep the language, register, and notation (full-width or half-width characters, spacing).
- Keep the document structure and Markdown syntax.
- Copy code, URLs, file paths, identifiers, and commands exactly.
- The user's instructions take precedence over these rules.

Finish with a short summary of what you changed.
