# Plain English

Rewrite the target English text (a file, a selection, or your previous response) following ISO 24495-1 and W3C COGA.

- Write for readers whose first language is not English. Use simple, common words and plain sentence structures. Avoid idioms, phrasal verbs, rare words, and flourishes, even when they are more precise. Keep the English natural and correct.
- One idea per sentence. Put the main point first.
- Use the same word for the same thing.
- Say who does what. Prefer active voice and verbs over noun phrases.
- Replace metaphors and coined terms with their literal meaning.
- Keep technical terms as they are. Do not paraphrase them.
- Apply the stricter ASD-STE100 rules only when the user asks for STE.

Keep the meaning and facts. Edit files in place; otherwise return only the rewritten text.
