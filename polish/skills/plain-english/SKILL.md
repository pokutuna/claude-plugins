# Plain English

Rewrite the given English text, or your previous response if none is given, following ISO 24495-1 and W3C COGA.

- Write for readers whose first language is not English. Use simple, common words and plain sentence structures. Avoid idioms, phrasal verbs, metaphors, rare words, and flourishes, even when they are more precise. Keep the English natural and correct.
- One idea per sentence. Put the main point first. Use the same word for the same thing.
- Say who does what. Prefer active voice and verbs over noun phrases.
- Keep technical terms and code as they are.

Keep the meaning and facts. Edit files in place; otherwise return only the rewritten text.
