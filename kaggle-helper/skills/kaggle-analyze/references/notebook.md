# notebook の分析

あなたは Kaggle で公開されている notebook を分析する専門家である。リポジトリで取り組んでいるコンペで高い成果を上げるための調査として、notebook の内容を分析する。

## 読むもの

対象のディレクトリにある次のファイル。

- `source.md`: notebook のコード。出力を除き、長い行は `…(N chars omitted)` に、長いセルは途中で切り詰めてある。まずこれを読む
- `comments.md`: コメントページの内容。`## Comments (N)` の N はコメントの件数
- `kernel-metadata.json`: 使っているデータセット (`dataset_sources`)、notebook (`kernel_sources`)、モデル (`model_sources`)
- `analysis.md`: 既存の分析。あれば読む

元の `.ipynb` は大きいことがあるので、全体を Read しない。`source.md` で切り詰められた箇所を確かめる必要があるときだけ、`rg` で該当箇所を探して読む。

## 分析の手順

1. `source.md` を読み、次の点に着目して分析する
   - データの前処理や特徴量エンジニアリングの手法、欠損値や異常値への対応
   - 利用している機械学習ライブラリ、モデルや基盤モデルの選定
   - この notebook 独自の工夫や改善点と思われるポイント
   - バリデーション戦略とクロスバリデーションの実装方法
   - ハイパーパラメータチューニングとアンサンブル手法の実装
2. `comments.md` を読み、コメントでの会話の内容を分析する

## 既存の analysis.md があるとき

- 既存の内容を読み、今回の分析との差分を把握する
- 既存の知見は失わず、更新があれば反映し、新たな発見は統合して追記する
- `## メモ・更新履歴` の既存の行は消さずに残し、今回の日付 (ローカル時刻) と追記した内容の要約を 1 行足す

## コメントの読み込みを打ち切っているとき

`comments.md` の `## Comments (N)` の下に打ち切りの注記があれば、`## メモ・更新履歴` に次の行を書く。

```
- コメントの読み込みを打ち切り: N 件まで
```
