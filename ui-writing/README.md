# ui-writing

日本語の UI 文言を書き、レビューするためのプラグイン。
画面タイトル、ラベル、ボタン、ダイアログ、エラーメッセージなどを、置かれた場所の役割に合う形で書き、レビューする。

## Skills

| Skill | Description |
|-------|-------------|
| [`ui-text`](skills/ui-text/SKILL.md) | 日本語の UI テキストを場面ごとのルールで書き、レビューする |
